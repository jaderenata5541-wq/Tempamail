# Correo Temporal – Generador de Email Desechable

Este repositorio contiene una demostración estática del proyecto oficial  
**CorreoTemporal.com.mx** – un generador de correos temporales en México.

🔗 Sitio oficial: https://correotemporal.com.mx/

## ¿Qué es un correo temporal?

Un correo temporal es una dirección de email desechable que puedes usar para:
- Registrarte sin usar tu correo personal
- Evitar el spam
- Recibir códigos de verificación
- Proteger tu privacidad online

## Versión Demo del Generador

Incluye un ejemplo básico en HTML + JavaScript que genera un email temporal sin backend.
